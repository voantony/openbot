### Changed

- Server layout now has three choices: server menu, separate server rail, and servers in the page rail. The separate server rail stays as an option for many servers. The new servers-in-page-rail layout is the compact choice for few servers: it lists servers in order in the leftmost rail, with the active server highlighted in place, and no second copy of it at the bottom. The app does not switch layouts by server count; the choice stays with you. Cmd+1-9 (Ctrl+1-9 on Windows and Linux) selects the server in that position in the list, the number shows in each server tooltip, and the numbers never change when you switch servers. Favorite servers to keep them in the first column: right-click a server and choose Favorite server, or Unfavorite server to remove it. With no favorites, the first column shows all servers. Hover a server tab in the first column to open a second column with all servers; it closes when the pointer leaves it. The list has an add button, and each server button keeps its context menu with mute, settings, restart, leave, and the other server actions. The layout switcher stays in the server menu at the top of the sidebar. Drag to reorder is available in the separate server rail and in the second column; in the first column, move a remote server with Alt+Arrow Up or Alt+Arrow Down. Favorites stay on this computer only. The web client keeps the separate server rail.
