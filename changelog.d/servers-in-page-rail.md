### Changed

- Server layout now has three choices: server menu, separate server rail, and servers in the page rail. The separate server rail stays as an option for many servers. The new servers-in-page-rail layout is the compact choice: it lists servers in canonical order in the leftmost rail, with the active server highlighted in place, and no redundant second copy at the bottom. The app does not force layout switching by server count; the choice stays with you. Cmd+1-9 (Ctrl+1-9 on Windows and Linux) selects the server in that position in the list, the shortcut displays in each server tooltip, and server buttons retain their full context menus (settings, mute, leave, delete, restart). Reorder remote servers using Alt+Arrow Up or Alt+Arrow Down. An add server button is included directly in the rail for quick access. The layout switcher remains available in the server menu at the top of the sidebar.
